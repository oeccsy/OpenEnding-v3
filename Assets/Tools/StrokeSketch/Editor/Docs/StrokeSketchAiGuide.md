# StrokeSketch AI 안내

MCP 도구 `stroke_sketch`로 그림을 그리는 AI를 위한 안내다. 사람용 그림 설명은 같은 폴더의 SketchSettingsGuide.html에 있다.

## 1. 이 도구의 목적

손그림 **드로잉 모션그래픽**의 원본을 만든다.

- 그린 획은 export로 JSON(Assets/Resources/Drawings)에 저장되고, StrokeMotion 플레이어가 **획을 저장된 순서대로, 각 획을 시작점에서 끝점 방향으로** 하나씩 그려 나가는 애니메이션으로 재생한다.
- 그래서 결과물은 정지 그림이 아니라 "그려지는 과정"이다. **획의 순서와 방향이 곧 연출**이다.
- 프레임을 여러 장 캡처해 이어 붙이는 플립북은 이 도구의 목적이 아니다. 움직임은 플레이어가 만든다.

## 2. 사람이 그린 것처럼 연기한다

이 도구의 결과는 사람이 손으로 그린 그림처럼 보여야 한다. 깔끔한 도형 좌표를 그대로 넣으면 "그림판" 같은 결과가 나온다. 다음을 지킨다.

- **선에 흔들림을 넣는다.** 직선과 곡선을 촘촘한 점(약 6~15 간격의 L 명령)으로 나누고, 진행 방향의 수직으로 낮은 주파수의 작은 어긋남(굵기 4~6이면 1~3, 굵기 12 안팎이면 2~4)을 준다. 점마다 무작위로 튀게 하면 지저분해진다. 천천히 출렁이게 한다.
- **완벽하게 닫지 않는다.** 원이나 고리는 시작점과 끝점이 살짝 어긋나거나 조금 겹치게 끝낸다.
- **끝을 살짝 지나치게 그린다.** 선이 만나는 곳에서 몇 픽셀 넘어가게(overshoot) 끝내면 손맛이 난다.
- **같은 모양도 조금씩 다르게 그린다.** 날개 4개, 별 2개처럼 반복되는 모양은 크기, 각도, 곡률을 조금씩 바꾼다.
- **사람의 순서로 그린다.** 큰 윤곽 → 안쪽 부분 → 작은 장식 순서, 대체로 위에서 아래, 왼쪽에서 오른쪽. 한 획은 사람이 펜을 떼지 않고 그을 만한 단위로 나눈다.
- **다듬기를 약하게 한다.** 다듬기가 강하면 넣은 흔들림이 지워진다. 손그림 느낌에는 `smoothing_radius` 0~2, `tolerance` 1.5~3을 권한다.
- **작은 디테일은 다듬기를 끄고 그린다.** 크기가 수십 px 이하인 모양(입, 눈썹, 작은 기호)은 위 값으로도 뭉개진다. 예를 들어 폭 24px 높이 5px의 ω 입은 tolerance 2에서 그냥 미소 곡선이 된다. 이런 획은 `smoothing_radius` 0, `tolerance` 1로 그리고, 꺾이는 곳마다 획을 나누면 모양이 산다. 다 그린 뒤 다듬기 값을 원래대로 되돌린다.
- **굵기로 재료를 고른다.** 4~6은 연필, 10~14는 크레용이나 색종이, 20 이상은 마커 느낌이다. 따뜻하고 살짝 탁한 색(예 : #E2574C, #F2B134, #3FA34D, #2F6FDB, 연필 #333333)이 잘 어울린다.

## 3. 작업 순서

1. `get_guide` : 이 문서를 읽는다(처음 한 번).
2. `get_settings` : 캔버스 크기와 지금 설정을 확인한다. 좌표는 이 캔버스 기준이다. `capture`로 캔버스에 이미 그려진 획이 있는지도 본다.
3. `set_settings` : 펜 색, 굵기, 다듬기 값을 정한다. 준 값만 바뀌고, 다시 바꿀 때까지 유지된다. 색이나 굵기를 바꿀 때마다 부른다.
4. `draw_svg_path` 또는 `draw_svg` : 그린다.
5. `capture` : 돌려받은 PNG 경로의 파일을 읽어 눈으로 확인한다. 이상하면 `undo`(마지막 획부터 `count`개, 기본 1) 또는 `clear`(전체)로 지우고 다시 그린다. 지우기는 끝에서부터만 되므로, 고칠 가능성이 큰 부분(얼굴 같은 작은 디테일)은 무리별로 그린 직후 캡처해서 확인하고 다음 무리로 넘어간다. 그려 넣은 경로는 다시 그릴 수 있게 직접 보관한다.
6. `export` : 이름을 정해 저장한다. 같은 이름이 있으면 덮어쓰지 않고 오류를 돌려준다. 응답의 `playerPath`를 플레이어에서 쓴다.

### action 목록

| action | 인자 | 하는 일과 응답 |
|---|---|---|
| get_guide | 없음 | 이 문서를 돌려준다 |
| get_settings | 없음 | 지금 설정(아래 6장의 인자 이름 그대로)을 돌려준다. 바꾸지 않는다 |
| set_settings | 6장의 설정 인자 중 바꿀 것만 | 준 값만 바꾸고 전체 설정을 돌려준다. 값이 틀리면 하나도 바꾸지 않고 오류 |
| draw_svg_path | path_data | 지금 설정으로 그린다. 응답의 drawnStrokes에 그린 획마다 index(0부터, 전체 획 중 순번)와 curveCount가 있다 |
| draw_svg | svg (문서 전체 텍스트) | 5장 규칙으로 그린다. 응답은 draw_svg_path와 같다 |
| capture | 없음 | 완성된 획을 캔버스 크기 PNG로 저장하고 전체 경로(path)를 돌려준다. 그 파일을 읽어 눈으로 확인한다. 배경은 미색 종이(#FDFAF3)다 |
| undo | count (기본 1) | 마지막 획부터 count개를 지운다. 남은 획보다 많으면 하나도 지우지 않고 오류. 어떤 무리부터 지우려면 그 무리 첫 획의 index를 기억해 두고 count = 전체 획 수 - index로 센다 |
| clear | 없음 | **확인 없이 모든 획을 지운다. 되돌릴 수 없다.** 캔버스에는 사람이 그린 획이 있을 수 있으니 부르기 전에 capture로 확인하고, 자기가 그린 것만 지울 때는 undo의 count를 쓴다 |
| export | name (확장자 없는 파일 이름) | Assets/Resources/Drawings/{name}.json으로 저장한다. 같은 이름이 있으면 덮어쓰지 않고 오류. 응답의 playerPath("Drawings/{name}")를 플레이어에서 쓴다 |

## 4. 좌표와 경로

- 캔버스 좌표는 왼쪽 위가 (0, 0)이고 y는 아래로 커진다. 기본 캔버스는 1920 × 1080이다.
- `draw_svg_path`의 `path_data`는 SVG path의 d 속성이다. 지원 명령 : M L H V C S Q T Z(대소문자). A(호)는 지원하지 않으므로 C로 바꿔 쓴다.
- **M마다 새 획**이 된다. 한 번 호출에 여러 획을 넣을 수 있지만 모두 같은 설정으로 그려진다.
- 이동만 하고 끝난 M은 획이 되지 않는다.
- **점 찍기** : `M x y l0 0`처럼 길이가 0인 획을 넣으면 펜 굵기만 한 둥근 점이 된다. 눈, 코, 반점에 쓴다.

## 5. draw_svg (SVG 문서 통째로)

- viewBox(없으면 width, height)를 캔버스 가운데에 비율을 지켜 가장 크게 맞춘다.
- path, line, polyline, polygon, rect, circle, ellipse의 **윤곽**을 문서 순서대로 획으로 만든다.
- SVG 안의 색, 굵기, 칠(fill)은 쓰지 않고 지금 설정으로 그린다.
- **칠로 된 SVG는 두 줄이 된다.** PNG 윤곽 추적이나 면 위주 아이콘처럼 굵은 선이 "칠한 면"으로 들어 있으면, 면의 안쪽과 바깥쪽 테두리가 각각 획이 되어 평행한 두 줄로 나온다. `fill="none"`에 `stroke`로 그린 선 그림 SVG를 쓴다. 칠로 된 그림은 보고 `draw_svg_path`로 다시 그리는 편이 낫다.
- transform이 있으면 오류다. rect의 둥근 모서리(rx, ry)는 직각으로 그린다. defs, clipPath, mask, symbol, marker, pattern 안쪽은 그리지 않는다.
- 깔끔한 SVG를 그대로 넣으면 2장의 손그림 느낌이 나지 않는다. 손그림이 목표면 경로를 꺼내 흔들림을 넣어 `draw_svg_path`로 그린다.

## 6. 설정 값

| 인자 | 범위 | 기본 | 뜻 |
|---|---|---|---|
| color | #RRGGBB, #RRGGBBAA | #000000 | 펜 색. 모양 처리에는 영향이 없다 |
| width | 0.5 ~ 100 | 20 | 펜 굵기(캔버스 좌표 단위) |
| canvas_width, canvas_height | 0보다 큼 | 1920, 1080 | 캔버스 크기. 다른 거리 값의 단위가 된다 |
| target_spacing | 1 ~ 12 | 4 | 획을 따라 점을 이 간격으로 다시 찍는다. 크면 작은 굴곡과 뾰족한 모서리가 사라진다 |
| corner_angle | 10 ~ 181 | 60 | 이 각도 이상 꺾인 곳을 모서리로 남긴다. 181이면 모서리 찾기를 끈다 |
| corner_speed_ratio | 0 ~ 1 | 0.4 | 획 속도 중앙값 대비 이 비율 아래로 느려진 곳은 꺾임이 corner_angle의 절반만 넘어도 모서리로 본다. SVG 입력은 속도가 일정해 영향이 거의 없다 |
| smoothing_radius | 0 ~ 10 (정수) | 3 | 앞뒤 이웃 점 평균으로 떨림을 줄인다. 0이면 다듬지 않는다. 크면 흔들림이 사라진다 |
| tolerance | 0.5 ~ 12 | 4 | 곡선 맞추기 허용 오차. 작으면 원래 모양을 따라가고 곡선이 많아진다. 크면 매끈하고 단순해진다 |

## 7. 알아 둘 한계

- 닫힌 획(원, 고리)은 이음매가 살짝 뾰족해질 수 있다. 완벽하게 닫지 않고 살짝 겹치게 그리면 덜 보인다.
- Unity가 스크립트를 다시 컴파일하면 캔버스의 획이 사라진다. 오래 걸리는 작업은 중간에 export해 둔다.
- 선 굵기는 획마다 고정이다. 한 획 안에서 굵기가 변하지 않는다.
